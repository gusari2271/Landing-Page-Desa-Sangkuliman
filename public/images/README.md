# Panduan Aset Foto Desa Wisata Sangkuliman

Folder ini berisi direktori foto untuk setiap destinasi dan section website Desa Wisata Sangkuliman.

## Standar Penamaan File
Untuk setiap folder destinasi, gunakan standar penamaan berikut:
- `cover.jpg` : Foto utama untuk cover/header (rasio 16:9 atau landscape lebar, min. 1600x900px).
- `1.jpg`, `2.jpg`, `3.jpg`, dst. : Foto-foto dokumentasi pendukung untuk blok split (kiri/kanan) dan galeri carousel.
- Format disarankan: `.jpg`, `.jpeg`, atau `.webp` (dikompresi untuk web agar performa cepat).

## Daftar Folder & Peruntukan Foto:
1. `hero/` : Foto panorama udara desa / pemukiman terpadu / Danau Semayang untuk latar Hero Beranda.
2. `pesut-mahakam/` : Foto kemunculan Pesut Mahakam di anak Sungai Mahakam / rakit apung / tepi sungai.
3. `tari-jepen/` : Foto pementasan Tari Jepen Putri Penjaga Kampong oleh Sanggar Seni Saguntur BMT.
4. `gunung-tallo/` : Foto gundukan tiga, akar jaraya membentuk gerbang, dan pohon-pohon langka.
5. `tanjung-rappeh/` : Foto sunset di ufuk barat Danau Semayang, hamparan rumput kemarau, dan pohon berdiri kokoh di dalam air saat banjir.
6. `tanjung-palla/` : Foto tanjung, benteng pemecah ombak, dan edukasi gembala sapi kalang.
7. `tanjung-hallat/` : Foto pulau tengah danau 13.000 ha, plang 'TANJUNG HALLAT', tenda camping, pohon tahan air, dan aktivitas nelayan (rawai pakal, reba, tamba udang).
8. `pemukiman-1990/` : Foto rumah kayu berhalaman bunga, jalan jembatan ulin/semenisasi, instalasi air bersih hibah 2024, foto udara pemukiman rapi.
9. `luah-palla/` : Foto percabangan sungai alami, kapal feri/long boat melintas, gotong royong membelah gulma.
10. `luah-ulaman/` : Foto susur sungai, alat tangkap Sangga berbentuk rakit, sapi berenang di tepi danau.
11. `luah-kijang/` : Foto sungai kecil membelah rimba rimbun, pagar ranting Reba di tepian.
12. `danau-saguntur/` : Foto danau luas, pohon penunggu danau setinggi 40m di tengah danau, keramba ikan, perahu tradisional ulin.
13. `bekantan/` : Foto kawanan bekantan di pepohonan RT 001, pohon duri/parupuk/bangalon.
14. `sport-tourism/` : Foto lapangan sepak bola dataran tinggi, wisatawan bermain bola & pemukiman rapi.
15. `kuliner/` : Foto Iwak Basumap, kue basah (Kikicak, Kalalapon), kue kering (Sampret Mak Jaleha, Baulu, Ruti Balok, Kacang Sembunyi, Cincin, Kerupuk Ikan).
16. `kedai-bmt/` : Foto Kedai BMT di ujung perkampungan, suvenir baju BMT, sahung, alat nelayan, dan kopi BMT.
